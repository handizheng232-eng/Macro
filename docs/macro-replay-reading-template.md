# 宏观复盘：获用户确认的阅读布局模板

> 用户已批准《加速Taper与转鹰准备》与《加息启动与缩表定调》的最终导语修订，并确认为后续复盘开头写作基线。复用主线、预期—现实比较、经济机制与机构假设的写法及阅读结构，不硬套本次历史事实；完整研究、来源、配额与另行发布授权要求不变。

适用于用户授权新建或改版的宏观复盘页面。阅读布局以第三篇用户确认的三级目录版为准，优先于旧第二篇的阅读布局；研究数据、五主题与来源契约仍按任务合同。不自动改写其他已发布篇目，不将模板保存当作额外发布授权。

## 页面与目录结构

- 保留篇目机制名称和时间范围；正文采用十进制编号，目录与标题同源生成编号，不将序号写入研究JSON、source ID或路由slug。
- 侧边目录仅三级：一级大板块 → 分析主题 → 栏目。单日资料、具体文章和单条复盘不放目录，但保留正文、日期、编号与深层来源锚点。
- 每个主题的直接栏目依次且固定为：阶段总结；观点 / 事前预期；现实；机制；分歧 / 预期差；市场含义；实例 / 原文与数据；验证条件。
- 重要一级板块包含综合市场分析、市场预期与现实路径对照等实际已有模块，编号依实际顺序派生，不硬编码某模块必为第几。
- 不新增独立事件时间轴。模板不展示“宏观框架辅助图表”区域，保留真正的市场路径对照图、来源追溯和原始数据；迁移其他旧篇需另获授权。

## 折叠与导航

- 一级长板块、分析主题、八栏目均可独立折叠，长正文默认收起，标题/简短判断保持可见。父级关闭后重开保留子级状态。
- 批量展开/收起的范围清晰，不顺便打开数百条来源明细。
- 桌面右侧本篇目录sticky跟随，可独立滚动与收起，随阅读高亮；窄屏用可关闭目录面板，不遮正文或全站底部导航。
- 目录/引用跳转先展开所有必要祖先，再定位与聚焦，不替换hash路由。阅读第四级正文时高亮所属第三级栏目。
- 保留页面回顶、板块回顶及“返回刚才阅读位置”。返回按稳定锚点+视口偏移保存，适应上游高度变化及祖先重新展开；支持正常和减少动画模式。

## 排版

- 编号使用不收缩且不换行的独立列；标题可自然换行，续行与文字起点对齐；折叠箭头固定占位。日期是独立次级信息，不插入编号或割裂标题。
- 桌面有空间时不强制断行，手机不靠整标题nowrap、截断重要标题或横向溢出掩盖问题。
- 一级、主题、栏目层级清晰，字号、字重、间距与分隔统一；样式限定当前获授权页面，避免全局semantic选择器泄漏。

## 验收

- 真实桌面、中间宽度和手机检查默认/全展两种布局；正文与目录三级编号、标签、顺序等值，无日期第四级条目。
- 测试全部栏目跳转开祖先、滚动高亮归属、往返位置、键盘、页顶/节顶、手机开关及无遮挡；用DOM几何核编号/标题/按钮无错行重叠。
- 所有新增研究段落展开后完整，严格历史模式保持真正卸载，原引用和关键行情图可用；未授权篇目不变。
- 纯UI改版核原研究data文件SHA不变；完整测试、lint/build以及本地HTTP/资产读回。明确获准发布后再检查CI与线上同样交互，交付带版本参数的精确页面链接。

## 导语展示与语义验收补充

获授权改写的研究导语执行 [EditorialOpenings长期规范](macro-replay-editorial-openings.md)。阶段总结首段突出主线矛盾；预期、现实、机制、预期差四栏各自先给实质导语，现实先讲实际走向，再用可核事前基准比较，不强凑超预期。按两篇×五主题×五类开头建立50单元矩阵，展开祖先后逐段读回全文，而非仅断言隐藏DOM存在。同步实际展示字段与fallback镜像，保原逐月正文、引用、图表与严格历史卸载。机构比较自然解释经济假设，不用审核操作语占据正文。本补充不改变八栏目、三级目录和独立折叠，不自动发布。

## FinalPass01：现实比较与经济正文

经济正文不因缺少调查基准而变成审计免责声明：先解释事实如何检验供给、需求或政策假设，把基准缺口记入方法/缺口元数据及 expectation-pairing。已有具体可比机构水平或区间时，不能以缺少市场一致预期为由回避比较；明确机构、信息日、条件与期限，区分阶段越过原估计水平和到期预测评分。
