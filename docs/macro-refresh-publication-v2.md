# 编辑版之后的数据刷新发布合约（02）

本合约只准入美国宏观九模块的五份数据快照。历史研究文本、资格标志、图表和前序发布回执不随刷新重新授权。

## 冻结链

- 编辑版批准基线：`a2069bdd9aaaa8366944a1e7d5e34c58dc47fa15`。
- 复用既有 `editorial-baseline-2e4d735.zip`，新增 `macro-refresh-base-a2069bd.delta.zip`；薄增量只保存15个必要差异文件，不再套娃复制大档案。
- 薄增量整体SHA、引用档案SHA、249个恢复后公开文件的逐文件SHA，以及唯一、规范、安全的成员路径均检查。没有私有原件或认证信息。
- 编辑版6个原测试在精确a2069版本运行，再由原编辑门禁重放PCE、旧宏观与研究测试，共54个原用例。原验证器、断言、回执及公开快照不修改。
- 全量数据runner仍发现所有 `scripts/test_*.py`，当前数据测试针对当前五JSON运行；历史用例分版本运行。记录实际启动的当前case ID，并与继承case ID合并，要求多重集等于全部发现ID，且没有跳过、预期失败或导入错误。

## 当前数据准入

`verify_macro_refresh_v2_publish.py` 读取独立回执 `release/macro-refresh-publication-02.json`。五JSON内容可以因新观察值或正式修订改变；不把本轮数据哈希当作永久研究规则。

回执绑定五文件SHA、真实取得时间、构建产物、必要基础设施及来源审计/完整前端/完整数据/页面验收证据SHA。`make_receipt` 的发布授权和页面QA参数默认均为false，必须在实际验收后显式传入。单元测试使用的内存回执不是发布回执。

独立语义检查包括：

- 源身份、单位、频率、系列/行身份和图表标题；数值有限，轴有序唯一，日期和值长度一致。
- 固定批准基线的可用历史不得被截短。对受保护的日频转月末构造，允许最新未完月份的实际末观察日向后移动，不能删除较早月份或制度首日，不能以null替换有效观察。
- CPI、就业、工资历史轴连续且保留缺口，最近表必须是历史表的准确投影；就业层级残差和与非农柱的差额重新计算，最近窗口按既定容差核对。
- GDP沿用现有发布精度预算函数，不改变阈值；Dallas PCE逐月六桶闭合，按实际分项权重重新分桶，并复算展示的质量统计。
- 公开CI不重查私人iFinD原始响应，也不假称做过这种核查。原始载荷身份、全历史取数、跨源核验、上一有效数据的逐项对账，由本地来源审计完成并保留独立证据。

非五JSON文件只能有本次明确列出的基础设施变化。工作流只允许将编辑版入口替换为继任入口；其余步骤、Node 22、`--testTimeout=12000 --maxWorkers=1` 均按基线原字节保护。两份路由测试可做本次已审查询性能修复，不改变交互、断言或时间预算。

## 每次刷新发布

1. 从远端最新已验收版本开始，在独立工作树取数。先备份，完整保存原始响应与取得时间；与上一有效五JSON对账，不改时间冒充新抓。
2. 全五文件候选核验后整批推广。滚动窗口源不得直接覆盖已留存的真实历史；需要合并时保留各段来源，无法证明的月份不得补造。
3. 用与CI一致的Node 22运行完整前端；本地完整数据runner使用已配置的Python及只读研究根。重型前端与浏览器验收串行，避免争用造成失真的超时结果。
4. 完成lint、build及当前页面验收后，生成本轮独立回执。不能回填/重绑前序回执。
5. 执行 `python -B scripts/verify_macro_refresh_v2_publish.py --legacy-tests --dist dist`；同时保留工作流其余所有门禁。
6. 检查暂存Git原字节、公开文件范围和精确SHA；基础设施与五数据提交分开审阅。上线后验证Pages目标SHA、CI产物与生产HTTP字节，以及九路由、温度表和PCE交互。

本机资源不足且完整前端仅出现超时时，可先推送 `automation/manual-refresh-*` 候选分支，由 `verify-macro-candidate.yml` 在干净的GitHub runner执行原样完整测试、lint、build和公开门禁单测。该流程只有contents只读权限，没有Pages配置或部署步骤。必须保留本地失败事实，核对候选SHA与远端完整结果，不能用定向通过替代全量通过；取得真实完整CI证据及本地数据/页面验收后才生成发布回执并推进main。正式部署流程仍再次执行全部原有门禁。

遇到新schema、来源身份改变、历史截断或研究内容变化，本合约应拒绝。先核实并另行审阅，不通过扩大容差、跳过测试或篡改旧批准记录放行。
