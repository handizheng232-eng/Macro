# 宏观复盘模板：综合分析与双层总结（v3）

本模板落实用户在2026年10月10日提出的最新规范，同时用于「政策反转」和「鹰派换届与反转酝酿」。它继承第二篇既有的证据、来源和历史边界标准，但替代旧模板中保留独立事件时间轴及简短综合分析的安排。页面仍以政策／市场机制命名，不把“第N章”作为可见名称。

共享实现为 `src/historyReplay.tsx` 与 `src/historyReplay.css`。第一篇资料截止2026年10月9日，第二篇阶段截止2026年8月31日，不因修改行文而自动延长窗口。用户于2026年10月10日验收后授权将两篇当前版本正式上线，并将本规范保存为后续复盘模板。今后新增修改仍先本地验收，再另获发布授权；其他时段不自动启动。

## 固定页面结构

保持主章节顺序、层级和布局，不为新时段复制一套UI：

1. 阶段机制名称、起止边界及资料截止日。
2. 四步复盘框架：事前预期 → 数据／政策事件 → 美债／美元重定价 → 后续验证／修正。
3. 综合市场分析：五个主题，默认展开。
4. 不再渲染「预期 → 现实：事件时间轴」。必要日期和事件信息纳入综合分析的对应主题；原始事件记录留作核验依据，不以改名或折叠方式恢复这一独立章节。判断与反证仍保留证据边界。
5. 星球、Wind、公众号三渠道观点，分别默认折叠。
6. 真实行情路径，明确单位、观测日、发布版本及缺失值。
7. 资料取得状态与月份×渠道配额矩阵。
8. 来源库／研报库默认折叠；逐月预期→现实和修正链、逐条对照及本地研究补充均嵌在此库内，不另增主章节。

五个主题为货币政策、通胀、增长与就业、美债收益率曲线、美元。每个主题及逐月分析都保留判断、事前预期、现实、机制、分歧／预期差、市场含义、验证条件及实际引用。综合分析是研究主体，不能以三渠道明细、长书目或事件罗列代替推导。逐月研究仍覆盖实际窗口内全部月份，修正链保留作者、日期、条件和期限，不复制别的阶段结论填位。

## 双层总结：先归纳，再展开

五个主题分别以详细的「阶段总结」开头，覆盖该主题在完整复盘窗口内的背景、关键转折、机制与条件分歧、资产路径、期末状态及待验证问题。分三至四个连贯段落，不以原核心判断的一句扩写、首末值比较或逐月流水账替代全阶段综合；详略按阶段长度及证据密度确定。

每个主题的七个展开方面——观点／事前预期、现实、机制、分歧／预期差、市场含义、实例、验证条件——均在时间线或详细展开之前写一段全面精炼的导读。导读先概括该方面的结构性结论、主要变化与关键条件，再让读者进入具体节点，不只重复小标题，不机械重复限制说明。

总结仅归纳本主题已经准入的研究节点，不新增事实、数字、时点、机构共识或因果认证。保存支持节点及原登记来源，主题总结使用 `periodSummary.paragraphs`，分项导读使用 `aspectSummaries[role].text`；两者仍属当前追溯研究，严格历史模式一并卸载。原节点、图表、出处及时间资格不改。

未知日期在阅读层只保留小号、低对比度的「日期未详」提示，完整说明可通过提示信息核查。不得大面积、醒目重复「日期未注明（不补造）」，也不能因此补造日期、删除未知状态或放宽历史筛选。

## 综合分析的写作与证据标准

- 按金融市场研究员的口吻写作：严谨、朴素、通顺。先说明事实和判断，再解释原因；少用压缩口号、拟人化词语和无出处的“市场认为”。专业术语需在相应上下文解释。
- 观点／事前预期与现实分别形成清晰的时间线。每个重要节点列日期、机构／作者、观察期、条件和期限；把事前预测、事后解释、官方公布及统计修订分开。月级资料不补造具体日。
- 机制按“前提 → 传导环节 → 可观察结果 → 适用条件／反证”展开。说明为什么同一数据可能对应不同政策和资产结果，区分会计关系、经济假设和因果识别；条件推论不能冒充已经发生的事实。
- 增加机制、分歧和实例的分析权重，目标为主题实质正文的一半或更多，但不以凑字数验收。证据足够时，每主题展开至少四个推导环节、三个有条件的分歧、两个原文或实际数据支持的实例；真正不足应说明缺口。
- 机构分歧须比较信息日期、指标版本、情景假设和预测期限，不靠机构数量投票。同机构不同署名、同作者修订和跨机构分歧分别标注；转录归属未独立核实的材料仍保留限制。
- 市场含义也按时间推进：判断提出时、现实公布后、后续研究调整及尚待观察阶段。分别讨论短端、长端、曲线和美元，不能用全阶段端点变化解释每个事件，也不能用缺失的CME／OIS定价制造预期差。
- 系统检索已经独立准入的研报储备，按主题选择更多独立作者和原文段落。标题相关不等于原文支持；新增引用必须有实际页／段位置、原件SHA和对应语句。重复分发不增独立证据数。

## 宏观九模块数据与图表联查

综合分析在相应主题内展示真实辅助图表，并链接实际框架模块。货币政策联查美联储与金融条件；通胀联查CPI／PCE、住房；增长与就业联查就业、GDP、消费、企业投资、PMI；美债联查财政与国债、美联储与金融条件；美元联查相对增长、政策路径及金融条件。

先锁定所用数据集及SHA，逐系列核指标身份、来源码、单位、频率、观察期、缺口和换算，再作图。保留数据库更新时间和版本；最新数据库的历史回溯只作明确标注的辅助图，不能替代当时的官方初值或给事前观点补充后发信息。正文中的现实结论仍以本阶段已核官方原稿与版本为准。严格历史截面卸载当前综合及其辅助图表。

## 日期与原文保护

阅读版采用“9月16日”“9月15日至9月16日”；跨年及可能混淆时写完整年份。结构化日期仍保存ISO值，月份和季度分别显示为“2026年9月”“2026年第二季度”，不把月级数据写成某一天。日期范围的两个端点应清楚，公布日期、观察期、修订日期及首次可得不得混用。

不得对所有斜杠机械替换：2年／10年期限组合、比值、原文件名、网址及内部标识不是日期。原PDF、原文引用、定位和文字哈希保持不变；如阅读层统一原文节选的日期写法，明确标注仅规范显示，不改原文。

## 研究与历史边界

- 先还原有出处的预期状态，再对应之后的现实与修正；不从结果倒推出事前预期。
- 机构预测、该报告记录的市场定价和全市场共识分开；同文跨渠道不增加独立票。
- 现实优先官方原稿，保留观察期、发布日、首报／修订版本。图表未OCR则不猜图内数字。
- 年底、未来季度及条件尚未发生的预测保留 `ongoing`／`unobserved`，不提前判对错。
- 广义美元不是DXY；国债利率变化、收益率曲线变化和投资回报分开，不用同期端点变化识别政策冲击的因果贡献。
- 首次历史可得未知的资料可用于当前追溯，不能进入严格历史截面。切换历史日期须卸载当前综合、逐月研究、修正链及其事后来源，而非只隐藏正文。
- 阅读版不显示内部长编号，但原数据、精确页／段位置和引用审计保留；来源与短摘录仍可查看。

## 新增原文的准入与阅读投影

原件已准入不等于本轮新增定位已准入。以冻结的旧载荷及其SHA为基线，另保存新版研究、逐页／段提取、独立语义审阅、逐项修订和父方接受清单，不覆盖原稿。哈希和字面相符只证明定位，不能代替对日期、数值、作者、条件和结论支持的语义检查。

每个新增研究节点用 `supportingEvidence` 提供可读署名、材料日期与PDF物理页／公众号段号；仅公开这些书目信息，不复制私有原句、完整原页或提取路径。作者、联系人、审核人、团队标签和转录自述分别说明。新增引用ID仍留数据与私有manifest，阅读版不显示长编号。书目记录数、不同SHA数、去重作品数和独立机构票数分开，不能互相冒充。

通用投影入口 `scripts/replay_editorial_projection.py` 接入已审研究及真实框架图表，拒绝未登记的出处／定位、主题错位及历史资格误升级。补充方法文献单独登记，发布日期未知不补取得日，不增加阶段官方事实或原文配额。旧行文的日期规范使用精确原句与SHA绑定的 `readingTextOverrides`；只改阅读层，数值比、期限、原文、文件名、机器日期和原件不改。

独立审阅发现错误后，按entry留修改前后、出处与日期变化及处理理由，再核原件／新定位。当前追溯节点引用晚发材料时，正文、日期说明与机器后发标记保持一致；一个统计容器含较晚字段，不意味着节点确实使用了这些字段，须核具体语句。

## 验收与发布

原PDF、公众号原HTML／全文、逐页文字和私有审计只留本机，不进公开git或Pages。公开层只含合规书目、短引、研究展示和验收摘要。

本机先完成文件SHA、双解析逐页、来源身份／标签／原文版本、观点定位、官方现实与历史边界复核；再重建公开载荷、完整测试／lint／build和桌面／手机浏览器验收。未授权修改的阶段数据SHA保持不变，共享主结构须保持无回归。

同时修改两篇的研究展示与共享UI时，保护已有原件、书目、定位和历史资格，不把旧候选或未准入观点重新接入。新研究扩展及图表映射保存独立manifest；逐步记录输入、来源选择、改动、检验结果及真实阻塞。新版未审核和获正式发布授权前，不重签线上回执；获授权后，以真实本机验收结果及确切公开载荷字节生成新回执。

发布门禁分两层：本地默认模式真实读回私有原件；公开CI使用 `release/replay-publication.json` 核对本地通过门禁时生成的两篇公开载荷SHA，并重新检查配额、引用、隐私与构建资产。CI不冒称重新读取本机私有原件。载荷一旦改变，旧回执失效，须重新本地验收后生成新回执。

交付前须核两篇主结构一致，独立事件时间轴确已删除，日期显示准确、比值未误改；每个主题的预期、现实和市场时间线可读，推导、实例和引用对应，实际图表非空且版本说明完整。完整测试、lint、build及桌面／手机浏览器验收通过后才展示给用户。另获正式发布授权后，再核确切提交与Actions结果，以及防缓存线上页面、实际月数、配额、历史切窗和手机布局；CI成功不替代线上验收。
