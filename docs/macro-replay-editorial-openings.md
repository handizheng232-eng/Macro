# 导语与机构比较：长期规范（EditorialOpenings v1.0）

> 用户已批准《加速Taper与转鹰准备》与《加息启动与缩表定调》的最终导语修订，并确认为后续复盘开头写作基线。复用主线、预期—现实比较、经济机制与机构假设的写法及阅读结构，不硬套本次历史事实；完整研究、来源、配额与另行发布授权要求不变。

适用于获授权的全部后续宏观复盘。本章覆盖旧模板中关于导语篇幅和作用的冲突要求，但不删除原有研究、配额、来源、阅读UI与发布门禁。此次仅修改两篇授权页面，先本地审核，另获明确授权才上线。

## 阶段总结先讲主线

每主题开头用一至两段讲清：阶段初态 → 核心冲突与约束 → 阶段内转折 → 经济含义与期末未解问题。以有因果含义的经济关系组织，不能用资料目录、机构名单或抽象标签替代分析。后续逐月事实、官方解释、具名机构分析和条件完整保留；篇幅服从证据，不为整齐删限定或凑字。

## 四类栏目各做一件事

| 栏目 | 导语任务 | 实际渲染字段 |
|---|---|---|
| 阶段总结 | 交代初态、矛盾、转折与意义 | `periodSummary.paragraphs[0]`（必要时第二段） |
| 观点 / 事前预期 | 谁在何时对什么期限作何判断，依赖什么假设；先讲主判断及关键分歧 | `aspectSummaries.expectationTimeline.text` |
| 现实 | 先概括实际走向和转折，再相对有来源的基准说明偏强、偏弱、相符或尚不能比较 | `aspectSummaries.realityTimeline.text` |
| 机制 | 冲击/约束 → 主体行为 → 价格或数量 → 政策与资产；区分核算、假说、因果识别 | `aspectSummaries.mechanism.text` |
| 分歧 / 预期差 | 哪条假设偏离、哪条仍成立、谁作了什么修订；信息日或期限不同不能强造对立 | `aspectSummaries.divergence.text` |

导语自成实质段落，不用一句“关注……”替代。现实与预期差允许讨论同一事件，但前者强调结果，后者解释原假设及修正，不复制整段。实际渲染以源码追踪为准；同步 `judgement/expectation/reality/mechanism/divergence` 等真实镜像，但不盲改逐月正文。新增导语必须能从可见栏目的已核来源追溯。

## 每项预期差的记录字段

`actor`、`forecastDate`、`firstAvailabilityStatus`、`targetMetric`、`targetPeriod`、`unitOrDirection`、`expectedValueOrDirection`、`conditions`、`outcomeReleaseDate`、`outcomeObservationPeriod`、`outcomeVintage`、`outcomeValueOrDirection`、`comparability`、`conclusion`、`sourceIds`、`supportLocator`、`privateContextHash`。

同指标、同期限、同口径配对。初报与修订分别讲，不能事后拿修订值重写当日惊讶。有可靠调查才称“高于/低于调查预期”；单家报告只能称“比某机构当时预计的更……”。方向预测只比较方向和出现时间，不造点差；没有可靠基准只描述实际强弱或转折，并自然说明尚不能确认超预期。未到期、篮子不同、公告与执行不同、首次可得未知均如实记录，不用算法自动评分。每主题不强制同时出现正负意外，不把更鹰或指标更高机械解释为资产利好/利空。

## 机构比较与文风

写得像研究员向同行解释：谁更看重需求、供给、反应函数、金融条件或期限，为何得出不同路径，什么变化会让原判断失效。句子自然，主体与动词明确，稍口语化但不戏谑。少用“不是……而是……”“多因素交织”“叙事/边界/条件性”堆砌，避免“A认为、B强调、三者并不矛盾”后没有经济解释。

只润色原创转述，不修改原引文、题名、数值或日期。保留“可能/如果”所承载的前提、期限、反例与风险；顺畅不能以扩大因果识别为代价。审核操作语移到方法或状态区，不放进经济解释。专业证据要求优先于机械反AI词表。

## 正反示例（以下均为合成写作示例，不是经济事实）

- 反例：“多因素交织，市场一致预期将转鹰，现实超预期，A与B并不矛盾。”缺主体、信息日、指标、期限及经济关系。
- 正例：“甲机构在某月会前预计首次行动较晚，前提是劳动供给继续回流；乙机构更担心供给缺口持续，认为等待会延长价格压力。随后官方指引前移，削弱了甲的等待假设，但尚不能当作行动已执行。”使用时必须将占位字段替换为真实已核材料。
- 反例：“本月增速高于上月，所以超预期。”前值不是事前预期。
- 正例：“本月增速较上月回升，但恢复主要集中在商品部门，服务需求能否接续仍决定增长的持续性。（合成示例；调查基准缺口另记方法元数据。）”
- 反例：“广义美元上涨，所以某机构的DXY目标兑现。”篮子不同。
- 正例：“实际可核的是广义贸易加权美元；DXY目标需相应行情及目标期限另验。”

## 50单元验收矩阵

两篇 × 五主题 × 五类开头 = 50个语义单元；增加篇目按实际授权数量计算。每格逐项人工审阅，关键词命中和字数不能证明语义通过：

- [ ] 起点、冲突、变化、经济意义有实质内容，各栏功能不同。
- [ ] 现实先讲走势，再按有出处基准比较；没有基准不强补。
- [ ] 机构分歧解释具体假设、信息日和期限，而非名单或投票。
- [ ] 每个新判断绑定既有公开source ID与私有上下文哈希/定位；当前版本指针核对。
- [ ] 预期差记录闭合，未到期/不同口径/缺调查如实保留。
- [ ] 文风自然但条件、风险、原引用与统计定义不变。
- [ ] 逐月正文、原节点ID、市场数值、图、来源资格和配额状态未越权改变。
- [ ] 展示导语与fallback/摘要镜像全文一致，修改前后和逆投影留档。
- [ ] 公共测试只读公开fixture；旧冻结证据与pins不重签，允许以显式逆投影验证原版本。
- [ ] 完整测试、lint、TypeScript/build通过；真实1440/900/390两路由展开读回全部导语。
- [ ] 五主题八栏目、编号、引用往返、严格历史卸载、图表日期与标签、无溢出和console异常均检查。
- [ ] 原件与长支持不公开；未获新授权不commit/push/deploy，编辑完成不升级研究资格。

## 模板与跨模型同步

将本规范连同主指令补丁和自检表复制到新的补充目录，明确应用于工作流包v1.1.0；旧包只读保留。项目写作模板、阅读模板和可移植入口均引用同一规范。技能入口的同名长期要求保持一致，若未来用户调整，以最新明确要求为准，不自动重写其他旧篇。


## FinalPass01：现实比较与经济正文

经济正文不因缺少调查基准而变成审计免责声明：先解释事实如何检验供给、需求或政策假设，把基准缺口记入方法/缺口元数据及 expectation-pairing。已有具体可比机构水平或区间时，不能以缺少市场一致预期为由回避比较；明确机构、信息日、条件与期限，区分阶段越过原估计水平和到期预测评分。
